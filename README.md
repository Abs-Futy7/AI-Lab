# AI Lab

University Artificial Intelligence laboratory projects implemented as one deployed application with two separate demonstrations.

## Project 1 — Emergency AI Search and Resource Allocation

Full documentation: [project-1/README.md](./project-1/README.md)

### Live application

- [Lab 1 — Emergency Route Planning](https://ai-lab-project-1.vercel.app/lab1)
- [Lab 2 — Emergency Resource Allocation CSP](https://ai-lab-project-1.vercel.app/lab2)
- [Lab 1 — Synchronized six-algorithm simulation](https://ai-lab-project-1.vercel.app/simulation)
- [FastAPI documentation](https://ai-lab-project-1.vercel.app/docs)

### Included algorithms

- Lab 1: BFS, DFS, Uniform-Cost Search, Iterative Deepening, Greedy Best-First, and A*.
- Lab 2: manual AC-3, MRV, Degree, LCV, Backtracking, Conflict-Directed Backjumping, and Min-Conflicts.

Lab 2 reuses Lab 1's Central Dhaka road graph, route accessibility, blocked-road scenarios, travel distance, estimated response time, and route geometry without combining the two visual demonstrations. The interface includes synchronized allocation steps, fleet/station readiness, compact emergency signs, larger readable text, labeled solver-flow diagrams, and radar/scatter/donut algorithm comparisons.
